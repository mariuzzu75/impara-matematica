IMPARO LA MATEMATICA
====================

Avvio:
1. Estrai la cartella imparo-matematica.
2. Apri index.html nel browser per provarla.
3. Per pubblicarla su GitHub Pages, carica tutti i file mantenendo la struttura delle cartelle.
4. In GitHub: Settings > Pages > Deploy from a branch, scegli il branch (es. main) e la cartella /(root).

Caratteristiche:
- 8 moduli di gioco
- 5 domande casuali per partita
- 7 livelli progressivi
- Punteggio e progressi salvati nel browser tramite localStorage
- Lettura vocale tramite sintesi vocale del browser
- Layout responsive per PC, tablet e smartphone

Nota:
I progressi sono salvati sul dispositivo e sul browser utilizzato. Se si cambia browser o si cancellano i dati del sito, i progressi non vengono trasferiti.
La voce dipende dalle voci italiane installate nel dispositivo.
